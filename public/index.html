Оценка работы оператора, где у каждого балла есть реплика-основание

CQA проверяет чаты и звонки на русском, казахском и английском по вашему чек-листу. Для каждого критерия — ответ, объяснение и ссылка на сообщение в диалоге. Спорную оценку оператор оспаривает, проверяющий пересматривает, итог пересчитывается.

Как проходит проверка

Модель отвечает только на вопросы чек-листа. Баллы, веса и итог считает код по правилам чек-листа, поэтому результат можно проверить и воспроизвести.

  1. Загрузка

    Набор по group_id из API, файл JSON или вставленный текст. Реплики бота и системные события — контекст.

  2. Промпт из чек-листа

    Критерии, шкалы и условия N/A берутся из текущей версии. Новый критерий работает без правки кода.

  3. Ответ модели

    По каждому критерию — допустимое значение, объяснение и номера реплик. Ответ проверяется по схеме.

  4. Итог и пересмотр

    Код считает баллы. Оценку можно оспорить, решение проверяющего пересчитывает итог.

Что умеет

Два рабочих контура из задания: оценка и работа с результатом.

Оценка

Редактор чек-листа
Критерии, секции, веса, тип ответа, шкалы и правила N/A. Каждое сохранение — новая версия, старые оценки хранят свою.
Пакетная проверка
Весь набор ставится в очередь. Очередь сохраняется и продолжается после перезапуска сервера.
Три языка и звонки
Один чек-лист для русского, казахского и английского. Звонки оцениваются по транскрипту, запись можно прослушать.
Прозрачность
Для каждой оценки сохраняются промпт и ответ модели. Результаты выгружаются в CSV и JSON.

Работа с результатом

Переход к реплике
Клик по обоснованию прокручивает транскрипт к сообщению. У звонка запись перематывается к этому месту.
Проверенный участок
Если действие пропущено, видно, какие реплики проверялись. Для N/A — какое условие выполнено.
Апелляция
Оператор выбирает критерий и пишет, с чем не согласен. Проверяющий видит оценку, обоснование и фрагмент диалога.
Решение и пересчёт
Проверяющий подтверждает или меняет оценку с причиной. Исходная оценка ИИ остаётся в карточке.

Расчёт итога

По правилам выданного чек-листа. Расчёт покрыт автотестами.

  1. «Да» даёт полный вес критерия, «Нет» — ноль.
  2. Шкала пересчитывается пропорционально весу: верхняя ступень даёт полный вес.
  3. Критерий с N/A исключается, его вес делится между применимыми, максимум остаётся 100.
  4. Итог округляется до двух знаков. Если применимых критериев нет, итог не считается.
  5. Грубая ошибка отмечается отдельно и не смешивается с баллами.
01, 04, 05, 06 — «Да» и верхние ступени60 из 60
07 Завершение — «Нет»0 из 5
02 и 03 — N/A, их вес 35 исключён—
Применимый вес65
