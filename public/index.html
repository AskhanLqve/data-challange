Как это работает

Модель отвечает только на вопросы чек-листа. Всю арифметику — веса, N/A, округление — считает код по правилам из чек-листа, поэтому результат воспроизводим и проверяем.

Загрузка

Набор по group_id из API, файл JSON или текст транскрипта. Реплики бота и системные события — контекст.

Промпт из чек-листа

Критерии, шкалы и условия N/A берутся из текущей версии чек-листа. Новый критерий применяется без правки кода.

Оценка ИИ

Ответ строго по схеме: для каждого критерия — допустимое значение, объяснение и номера реплик-доказательств.

Расчёт и пересмотр

Код считает баллы и итог. Оценку можно оспорить: проверяющий подтверждает или меняет её, итог пересчитывается.

Возможности

Оба рабочих контура из задания — оценка и работа с результатом.

Редактор чек-листа

Критерии, секции, веса, тип ответа, шкалы и правила N/A. Каждое сохранение — новая версия; старые оценки хранят свой снимок.

Доказательства в реплике

Клик по обоснованию прокручивает транскрипт к нужному сообщению. Для пропущенного действия — проверенный участок.

Звонки и запись

Встроенный плеер: кнопка ▶ у каждой реплики и переход по доказательству перематывают запись к нужному моменту.

Пакетная оценка

Весь набор в очереди с прогрессом. Очередь сохраняется на диск и продолжается после перезапуска сервера.

Апелляции

Оператор оспаривает критерий с комментарием. Проверяющий видит спорную оценку, обоснование ИИ и фрагмент диалога.

Прозрачность и экспорт

Трассировка: промпт и ответ модели для каждой оценки. Выгрузка результатов в CSV и JSON.

Правила расчёта

Точно по выданному чек-листу. Покрыто автотестами.

  • «Да» даёт полный вес критерия, «Нет» — ноль.
  • Шкала пересчитывается пропорционально весу: верхняя ступень — полный вес.
  • N/A исключает критерий, его вес перераспределяется между применимыми — максимум остаётся 100.
  • Итог округляется до двух знаков; без применимых критериев итог не рассчитывается.
  • Грубая ошибка — отдельная отметка, не смешивается с баллами.

Пример

Идентификация (вес 20) — N/A, контакт (вес 10) — «Нет», остальное — «Да».

применимый вес   = 100 − 20 = 80
набрано          = 80 − 10  = 70
итог             = 70 / 80 × 100 = 87.50

Интерфейс — веб-компонент на HTML, CSS и JavaScript без сборки, готовый к встраиванию в Dynamics 365. Сервер — Node.js без фреймворков, хранение — JSON-файлы.
